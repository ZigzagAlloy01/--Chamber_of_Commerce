About Me

I am a software development student interested in web technologies, programming, and accessible user experiences. Concerning backend development, I specialize in workflow automation and systems integration, with practical experience designing robust pipeline solutions using Python and managing complex enterprise systems, like Odoo ERP. I'm proficient in HTML 5, CSS 3, SQL, React, Node.js, Next.js and JavaScript, and I can provide professional frontend support. I design and deploy modular systems using MVC (Model–View–Controller) architecture and serverless cloud environments. I’ve built custom Content Management System (CMS) platforms from scratch, for a local editorial seal. I've used supabase to create databases using the SQL editor. I'm studying a bachelor's degree in Software Development, offered by Brigham Young University Idaho. I'm also a technical writer and editor, responsible for structural, grammatical, and orthotypographic revision of novels, short stories, technical and scientific manuscripts prior to official publication. In addition, I have proved experience in the synthesis and characterization of ceramic materials (Al₂O₃-CeO₂, Al₂O₃-TiO₂). My work, published in Elsevier (Colloids and Surfaces C), focuses on using Al₂O₃-CeO₂ for environmental remediation, and I provide interpretation for complex analytical techniques like SEM, FTIR, XRD, and particle analysis. This page showcases my coursework, learning progress, and current projects.
